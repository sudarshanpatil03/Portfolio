# 🚀 Sudarshan Patil — Personal Portfolio

## 🌐 Live Demo

🔗 **[View Portfolio →](https://sudarshanpatil03.github.io/Portfolio/)**

---

## ✨ Features

- 🎨 **Dark-themed modern UI** with cyan accent color
- 📱 **Fully responsive** — works on mobile, tablet, and desktop
- ⌨️ **Typed.js animations** — cycling role titles
- 🔄 **ScrollReveal animations** — smooth section entry effects
- 📬 **Functional Contact Form** — powered by Formsubmit.co (emails delivered to Gmail)
- 🏆 **Clickable Certifications** — direct links to credential pages
- 🗂️ **All Sections:** Home · About · Skills · Experience · Projects · Education · Certifications · Contact

---

## 🛠️ Tech Stack

| Layer | Technologies |
|---|---|
| **Structure** | HTML5 |
| **Styling** | CSS3 (Custom, no frameworks) |
| **Logic** | Vanilla JavaScript |
| **Animations** | ScrollReveal.js, Typed.js |
| **Icons** | Font Awesome 6 |
| **Fonts** | Google Fonts — Poppins |
| **Contact Form** | Formsubmit.co |
